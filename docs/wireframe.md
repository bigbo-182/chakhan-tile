## 모바일 UX 고려사항

- 하단 고정 플로팅 버튼: [전화하기] [카카오톡 상담]
- 갤러리는 1열 또는 2열 그리드로 전환
- 폼 입력 시 키보드 대응 (스크롤 처리)
- 터치 친화적 버튼 크기 (최소 44px)
